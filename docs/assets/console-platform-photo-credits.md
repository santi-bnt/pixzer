# Console showcase photo credits

The showcase uses real, background-transparent photographs. These derivatives were resized and converted to WebP for pixzer; the depicted hardware and photographic content were not redrawn.

The Nintendo DS source depicts the original clamshell model and shows both displays, hinge, directional pad, and face buttons. The Nintendo 64 source is one studio photograph of the console and its three-prong controller; the cable is part of that original composition.

The source and license information was checked on the linked Wikimedia Commons file pages.
